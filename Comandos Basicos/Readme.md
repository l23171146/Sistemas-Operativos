# Comandos básicos de la terminal de Ubuntu

## Descripción

Esta práctica tiene como propósito introducir el uso de comandos básicos de la terminal de Ubuntu para consultar el contenido de directorios, visualizar información detallada de archivos y navegar entre diferentes carpetas del sistema de archivos.

## Objetivos de aprendizaje

* Comprender el funcionamiento básico de la terminal de Ubuntu.
* Utilizar el comando `ls` para consultar el contenido de un directorio.
* Utilizar las opciones `-l`, `-a` y `-h` para obtener información adicional.
* Aprender a desplazarse entre directorios mediante el comando `cd`.
* Comprender el uso de `cd ..` para subir un nivel en la estructura de directorios.
* Utilizar `cd ~` o `cd` para regresar al directorio personal del usuario.

## Comandos utilizados//Codigo

En esta práctica se utilizaron los siguientes comandos:

```bash
ls
ls -l
ls -la
ls -lh
cd carpeta
cd ..
cd ~
```

## Conclusiones

La práctica permitió familiarizarse con el uso de la terminal de Ubuntu y con algunos de los comandos fundamentales para trabajar con el sistema de archivos. Se comprobó que mediante `ls` es posible consultar el contenido de un directorio y que sus diferentes opciones permiten obtener información adicional sobre los archivos, incluyendo archivos ocultos y tamaños en un formato legible.

También se practicó la navegación entre directorios mediante el comando `cd`, utilizando `cd ..` para regresar al directorio padre y `cd ~` o `cd` para volver al directorio personal. Estos conocimientos representan una base importante para continuar aprendiendo el manejo de sistemas Linux mediante la línea de comandos.
