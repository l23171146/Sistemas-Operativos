Sistemas operativos

El software que hace posible usar una computadora.

Un sistema operativo administra los recursos del equipo y proporciona el entorno donde se ejecutan las aplicaciones. Es el puente entre el hardware, el software y el usuario.

01 · Funciones

¿Qué hace un sistema operativo?

Coordina las partes esenciales del sistema para que diferentes programas puedan funcionar de manera ordenada y segura.

⚙️

Gestión de procesos

Organiza los programas que se están ejecutando, asignando tiempo de CPU y coordinando sus actividades.

🧠

Gestión de memoria

Controla el uso de la memoria RAM y asigna espacio a los procesos para evitar conflictos.

💾

Archivos y almacenamiento

Administra archivos, carpetas y dispositivos de almacenamiento mediante sistemas de archivos.

🔌

Dispositivos

Permite que el sistema y las aplicaciones se comuniquen con periféricos como teclado, pantalla, discos e impresoras.

🛡️

Seguridad

Controla usuarios, permisos y acceso a recursos para proteger la información y el funcionamiento del equipo.

🖥️

Interfaz de usuario

Ofrece interfaces gráficas o de línea de comandos para que las personas puedan interactuar con el sistema.

02 · Características

Lo que distingue a un SO moderno

Multitarea

Puede mantener varios procesos activos y repartir los recursos entre ellos.

Multiusuario

Puede gestionar cuentas y permisos diferentes para distintos usuarios.

Portabilidad

Los sistemas operativos se adaptan a diferentes tipos de dispositivos y arquitecturas.

Estabilidad

Busca mantener los servicios funcionando incluso cuando una aplicación presenta problemas.

Conectividad

Integra funciones de red para comunicación con otros equipos y servicios.

Escalabilidad

Puede aprovechar desde recursos modestos hasta hardware de alto rendimiento.

En pocas palabras: el sistema operativo no es solamente “la pantalla que vemos”; es la capa que coordina recursos, aplicaciones y dispositivos.
